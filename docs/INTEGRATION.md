# 集成边界

## ERP

ERP 负责客户需求、产品主数据和正式生产订单。MES 通过外部订单 ID 建立映射，不把 ERP 原始响应完整写入业务日志。同步必须带幂等键，重复事件返回第一次处理结果。

## 仓储

仓储系统负责物料库存和领料出库。MES 接收物料引用、数量和单位，不在公共示例中提供真实物料编码、库存、成本、供应商或库位。

## 飞书

飞书用于 SSO、待办和状态通知。通知只包含工单号、状态、计划时间和系统链接，不发送配方、客户、产量明细、不合格原因或附件。

## 适配器要求

- 对外部数据做类型、范围和必填校验
- 维护外部 ID 与本地 ID 的单独映射
- 所有写入事件使用幂等键
- 超时后先查询状态，再决定是否重试
- 记录请求 ID 和结果，不记录 Token 与完整正文
- 使用专用测试环境和最小权限账号联调
