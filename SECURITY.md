# Security Policy

## Supported version

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature when available. Do not open a public issue containing credentials, production data, tenant identifiers or exploit details.

This repository is a reference core and contract set. Deployers remain responsible for identity, authorization, device trust, data validation, transactional persistence, audit controls, backups and all applicable regulatory requirements.
